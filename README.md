# 🕵️ Доска расследований

Бесконечная пробковая доска для командных расследований: карточки-улики, иглы, нити, чат, напоминания, личные столы и история каждой заметки.

## Возможности
- **Главная**: создание дела с названием (пишется мелом), генерация кода `XXXX-XXXX`, вход по коду, недавние дела.
- **Набор бумаг**: полароид, фото, вырванный лист, стикер, карточка, подозреваемый, газетная вырезка, протокол, вещдок, карта, чек, папка дела, аудио-кассета, видео, 3D-улика, «?» + стартовые фотографии.
- **Свои файлы**: фото, видео, mp3/wav, 3D-модели `.glb/.gltf`, документы — кнопкой, перетаскиванием на доску или Ctrl+V.
- **Иглы и нити**: 📍 приколите карточку иглой → 🧵 кликните по ушку иглы → кликните по следующей.
  - 🔴 красная — точный факт · 🟡 жёлтая — неточный факт · 🟢 зелёная — рассуждение. Клик по нити — подпись, смена типа, «обрезать».
- **Карточка справа**: редактирование, «Дописать» от своего имени, вложения, связи, полная история правок с восстановлением версий.
- **Команда в реальном времени**: курсоры участников, живое перетаскивание, чат с файлами, напоминания (всем/конкретному человеку/по времени), ссылки на улики.
- **Авторство**: у каждой улики метка и цвет автора (цвет головки иглы тоже); клик по аватару — показать только заметки этого участника.
- **Личные столы**: у каждого участника своя доска для собственных теорий; остальные могут только смотреть. Улику со стола можно вынести на общую доску.

Горячие клавиши: `V` выбор, `H` панорама, `P` игла, `T` нить, `1/2/3` цвет нити, `Пробел`+мышь — двигать доску, колесо — масштаб, `Del` — удалить, `Esc` — отмена. `Shift` при протягивании нити — продолжить цепочку.

## Запуск локально
```bash
npm install
npm run dev
```
Без настроек сайт работает в **локальном режиме** (данные в браузере, синхронизация между вкладками). Для проверки совместной работы: «Войти в этой вкладке как другой участник» на панели «Улика».

## Онлайн для команды (Supabase, бесплатно)
1. Создайте проект на https://supabase.com.
2. SQL Editor → вставьте `supabase/schema.sql` → Run.
3. Project Settings → API: скопируйте `Project URL` и `anon public` ключ.
4. Локально: создайте `.env.local` по образцу `.env.example`.

## Деплой на Vercel
1. Залейте папку в GitHub (или `npx vercel` из этой папки).
2. В Vercel: Import Project → Framework: **Vite** (подхватится из `vercel.json`).
3. Settings → Environment Variables: `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY` → Redeploy.

> Доступ к доске — по коду (без регистрации). Не храните там по-настоящему секретные данные. Лимит файла на бесплатном Supabase — 50 МБ.
